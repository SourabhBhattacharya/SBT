Data-driven Supply Chain Optimization Projects

Data collection → Exploratory analysis → Optimization → Managerial recommendations

Common project guidelines
  1. Download the original dataset and document the source, fields and assumptions.
  2. Clean and aggregate historical data using Excel or Python. Use historical averages, medians or selected observed days to estimate model parameters.
  3. Formulate decision variables, objectives and constraints before implementing the model.
  4. Compare the optimized solution with a simple baseline using identical inputs. Verify feasibility and report solver status.
  5. Run five scenarios and quantify managerial recommendations. Submit original data, cleaned input tables, formulation, working model, results and assumptions register.

No machine learning or predictive modelling is required. Use Excel or Python for preparation; Python is recommended for larger routing models.
